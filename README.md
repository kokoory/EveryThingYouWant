# EveryThingYouWant

원하는 모든 것을 담는 저장소입니다.

## 시작하기

```bash
git clone https://github.com/kokoory/EveryThingYouWant.git
cd EveryThingYouWant
```

## 기여 방법

1. 이 저장소를 Fork 합니다.
2. 새로운 브랜치를 만듭니다. (`git checkout -b feature/my-feature`)
3. 변경 사항을 커밋합니다. (`git commit -m '새 기능 추가'`)
4. 브랜치에 푸시합니다. (`git push origin feature/my-feature`)
5. Pull Request를 생성합니다.
